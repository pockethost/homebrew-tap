# pockethost/homebrew-tap

Homebrew formula for the [PocketHost](https://pockethost.io) command-line tool.

```bash
brew install pockethost/tap/pockethost
```

Upgrade with `brew upgrade pockethost`. The formula is updated on every
[release](https://github.com/pockethost/pockethost/releases).

Looking for PocketOne? It has its own tap:

```bash
brew install pocketonehq/tap/pocketone
```
